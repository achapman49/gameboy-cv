Moves four things built in 2026 as the sole data specialist at Alpine Online

Report Ops: agent-run Power BI development and maintenance

Reports live as PBIP project files in Git, so agents can read and change them. New client reports are built and onboarded from a template. Change requests come in through a form that raises a GitHub issue. Agents review each issue, then either open a pull request with the fix or refer it back to me. I reviewed every pull request.

Stack Claude Code · Claude Code routines · PBIP · GitHub issues and pull requests

Auto EDA: automated exploratory analysis with a five-agent review layer

Takes market panel data through exploratory analysis, a generated notebook report and written commentary, each stage run by its own agent. Five reviewer agents, each with a different stakeholder persona, then read the first draft and file prioritised recommendations. Worker agents apply the high and medium ones in parallel and log each decision before the report comes to me.

Stack Claude Code · agent skills · Python · NielsenIQ panel data

POS Pipeline: supplier point-of-sale analytics product

A supplier-facing analytics product for retailer point-of-sale data. Retailer files flow through Cloud Storage and Dataform into a BigQuery warehouse, with data-quality assertions built into the pipeline. Designed end to end: hosting, data architecture, and a user-facing data entry and analytics app.

Stack Google Cloud Storage · Dataform · BigQuery · Power BI

Feed Match: product-mapping agent skill

An agent skill that maps a retailer's product feed to a client's own product catalogue, made to cut manual data entry on a small team. It is designed to be transferable, so it can be used in Claude or Copilot Cowork as needed. It reads a per-client knowledge file before each run and updates it afterwards, so what it learns about one client's products carries into the next run.

Stack Agent skills for Claude and Copilot Cowork · per-client knowledge files · Excel master lists
